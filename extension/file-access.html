One switch, then your file opens

OfficeMini opens a download by reading the file Chrome has just saved. That is the only way that works for export buttons, and for spreadsheets a site builds on the page.

Chrome keeps this off for every extension until you turn it on. It lets OfficeMini read files you download or open in Chrome; it does not send them anywhere.

  1. Click Open OfficeMini's settings.
  2. Turn on Allow access to file URLs.
  3. Come back here. The file opens by itself.
